# Planora frontend — Design reference

Tài liệu chính: [DESIGN.md tại gốc repo](../../DESIGN.md).

Bản chuẩn hóa ngày05/10/2026 theo cấu trúc getdesign.md, giữ phong cách B
kem/xanh rừng/editorial đã chọn. Token lấy từ CSS hiện tại; không đổi ứng dụng.
Đọc cả chín mục trước khi thêm/sửa frontend component.

- Hành vi nghiệp vụ vẫn theo [spec v3](../../docs/superpowers/specs/2026-09-29-ai-workflow-platform-v3-design.md).
- Root DESIGN.md phân biệt code đã có, backend online thực tế và roadmap;
  không coi signup/AI/execution là đang bật chỉ vì component tồn tại.
- System Design/DESIGN.md là tham khảo lịch sử, không là palette Planora hiện tại.
- Khi xuất frontend thành repo riêng, mang nội dung DESIGN.md chính sang gốc
  repo đó, không xuất riêng shortcut này hoặc tạo một bản token khác.

Bằng chứng triển khai UI trước đây giữ nguyên trong docs/handoff/log/UI-01→06
và lịch sử Git. Tài liệu này không sao chép token để tránh hai nguồn mâu thuẫn.
