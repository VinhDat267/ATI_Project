# AI backend status — 2026-09-17

## Current verdict

`AI-00_IN_PROGRESS`: the backend AI design gate is being prepared. The
application still runs only the `DEV_FIXTURE_PLANNER` path. No live model,
embedding provider, semantic retrieval, query expansion, repair, or local
replan result is claimed.

AI-00 is a design and evidence gate, not an AI quality pass. Its output is the
[AI backend design](superpowers/specs/2026-09-17-ai-backend-design.md) and the
[implementation plan](superpowers/plans/2026-09-17-ai-backend.md).

## Verified starting point

- `PlannerPort` is the engine seam; the engine parses `PlannerResultSchema`,
  validates the returned plan against the reviewed gateway, performs the
  read-only preview and creates the approval snapshot.
- `DEV_FIXTURE_PLANNER` is server-owned and accepts only the reviewed fixture
  prompts. It is lifecycle evidence, not AI evidence.
- Prompt builders already define planning, bounded repair, query expansion and
  local-replan language. Prompt text does not replace engine validation or
  policy checks.
- The reviewed runtime catalog is 8 `task_hub` tools plus 2 optional
  `filesystem` tools. Retrieval must consume this reviewed snapshot, never raw
  MCP annotations or arbitrary client-supplied launch data.
- PostgreSQL already contains the historical `tools.embedding`/pgvector shape,
  but the current API path does not yet populate or query an AI retrieval
  index. That gap is intentionally part of AI-01, not silently treated as
  implemented.
