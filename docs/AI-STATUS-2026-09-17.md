## Verified starting point

- `PlannerPort` is the engine seam; the engine parses `PlannerResultSchema`,
  validates the returned plan against the reviewed gateway, performs the
  read-only preview and creates the approval snapshot.
- `DEV_FIXTURE_PLANNER` is server-owned and accepts only the reviewed fixture
  prompts. It is lifecycle evidence, not AI evidence.
- Prompt builders already define planning, bounded repair, query expansion and
  local-replan language. Prompt text does not replace engine validation or
  policy checks.
- The reviewed runtime catalog is 8 `task_hub` tools plus 2 optional
  `filesystem` tools. Retrieval must consume this reviewed snapshot, never raw
  MCP annotations or arbitrary client-supplied launch data.
- Migration `0007` adds a separate `reviewed_*` catalog/index store: it never
  queries the historical raw `tools` table. A complete 8+2 snapshot plus
  matching provider/model/dimensions/preprocessing/content/catalog hashes is
  required before atomic activation. The current API still does not populate or
  query that adapter.

AI-03 local replan (offline / mock model slice):

- Engine AI ports & adapter: `LocalReplanPort`, `LocalReplanInput`, `AiReplanAdapter` with local scope invariant validation (`validateLocalScopeInvariants`), secret redaction via `safeProject`, bounded repair loop (max 3 calls), fail-closed error handling.
- Engine attempts & execution: `classifyOutcomeError` classifies `bad_args`, `bad_tool`, `bad_assumption`, `fatal` errorClass. Step attempt counting maintains strict monotonically increasing history across workflow versions.
- Safe write failure (`on_error: 'replan'`) and safe read failure trigger `executeReplan`.
- Replan creates a new immutable workflow version (`origin: 'replan'`), marks old approvals as `superseded`, dry-runs remaining steps to produce a fresh preview, and transitions run to `awaiting_approval`.
- Unknown write certainty strictly prohibits replan, transitioning directly to `reconciliation_required` (FR-EXE-12).
- Replan limit enforced: max 2 replans per run; exceeding limit fails with `"Local replan limit reached (2/2)"`.
- Lease/currentness gate: replan tokens fence owner, workflow version, count, and phase; stale lease/owner callbacks return the durable detail without terminal cleanup. Gateway currentness is checked before candidate publication and before preview publication. Replan dry-run attempt mutations use the same token guard.
