Các write test chỉ tác động database g1_it_* đã dọn sau suite.

## Ranh giới kiểm chứng

Approval/run/operation trong integration test được tạo bởi **SYNTHETIC_TEST_FIXTURE**. b02 dùng approval riêng từng write; chưa có controller chạy dry-run rồi tạo một preview/approval chung. Kết quả test không chứng minh HTTP/API, session login, engine, UI, planner hoặc LLM đã hoạt động.

Receipt replay qua tools/call chỉ dùng được khi approval còn approved/unexpired, run running và version hiện hành. Reconciliation read-only sau expiry/cancel, timeout mất response, crash giữa dispatch/commit và worker orphan recovery còn **NOT_RUN / chưa triển khai**. Restart test đã nhận phản hồi thành công trước khi restart, không phải fault test mất phản hồi.

5 task_hub tool còn lại, filesystem adapter/root confinement, ConnectionManager và preset enforcement còn SPEC_ONLY. `config/mcp-presets.json` giữ deny-all; server chưa được tự đăng ký vào Codex. Rubric, nhu cầu người dùng, model/provider và thí nghiệm AI vẫn OPEN. Không có kết nối Slack/Google thật.

## Chạy lại và bước tiếp theo

Từ root project với Node >=22 và Docker đang chạy:

```powershell
npm ci
npm run db:up:g1
npm run db:migrate:g1
npm run db:seed:g1
npm run check:g1
node scripts/g1-status.mjs
```

Hạ tầng đang chạy riêng: PostgreSQL loopback **55432**, Redis **56379**, project `ati-g1`, volume `ati-g1_g1_pgdata`. Dừng và giữ dữ liệu bằng `docker compose -f compose.g1.yaml stop`. Không dùng volume dev-services cũ. [MCP README](../apps/mcp-task-hub/README.md) ghi command/args stdio và điều kiện gọi write.

Bước tiếp theo: controller/engine tối thiểu cho plan tay b02 — read, resolve args, lưu snapshot bất biến, tạo/duyệt approval, claim operation rồi dispatch tuần tự và lưu trace. Cần kiểm payload thay đổi, expiry/double decision, crash/unknown trước khi nối UI/LLM. Hoàn thiện 5 task_hub tool + filesystem và nguồn rubric để chốt toàn bộ G1.

Nguồn kỹ thuật: [MCP tools specification](https://modelcontextprotocol.io/specification/2025-11-25/server/tools) cho outputSchema/structuredContent/isError; [Drizzle PostgreSQL](https://orm.drizzle.team/docs/get-started-postgresql) cho connection adapter. Bằng chứng chạy tại máy nằm trong [thư mục evidence](g1-evidence/2026-09-13/README.md).
