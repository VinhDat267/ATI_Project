## Legend
- **Capability Status:**
  - **REAL:** Full schema, planner routing, live adapter implementation, credential/token wiring, scope enforcement, and tests verified.
  - **PARTIAL:** Implemented with functional/architectural gaps, missing safety metadata, or incomplete workspace/pinned-scope revalidation.
  - **BROKEN:** Present in codebase/migrations, but fails deterministically at runtime due to missing wiring or incompatible contracts.
  - **LEGACY / DEAD CODE:** Historical code paths blocked at API entrypoints (e.g., `410 Gone`) or unreachable in production.
- **Evidence Classification Labels:**
  - **`CODE_TRACE_CONFIRMED`:** Proven by static source, SQL schema, and TypeScript contract trace at `08c8d8c5e7bf12625857ac3496fb96ec3914e34f`.
  - **`INTEGRATION_REPRODUCED`:** Proven by deterministic runtime reproduction against isolated PostgreSQL (`localhost:56534/ati_v3`) and mock providers.
  - **`NOT_TESTED`:** Requires live external third-party provider infrastructure not exercisable under the no-live-write audit constraint.
  - **`PRODUCT_GAP`:** Feature, workflow handoff, or UX capability is not implemented by current architecture/roadmap design.
