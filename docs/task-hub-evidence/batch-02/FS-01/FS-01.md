### 2) Bổ sung và Đặt lại tên Test Suite
- **Đổi tên P20:**
  - `P20a: accepts valid clean text in readBoundedUtf8` (đọc văn bản sạch).
  - `P20b: rejects lone surrogate byte sequences (CESU-8 surrogate halves) in readBoundedUtf8` (từ chối chuỗi byte CESU-8 surrogate `0xED 0xA0 0x80` với lỗi `BAD_CONTENT`).
- **Positive Test Leaf Write:**
  - Bổ sung `P16: accepts missing leaf in existing parent for write mode` xác nhận việc ghi file mới chưa tồn tại trong thư mục cha hợp lệ được chấp nhận thành công.
- **Short-Read Robustness Tests:**
  - `R5b: rejects over-limit file (>65,536 bytes) when read in small chunks` (tệp 65,537 bytes đọc theo chunks nhỏ 1024 bytes vẫn ném đúng `PAYLOAD_TOO_LARGE`).
  - `R5c: rejects file with invalid UTF-8 suffix or NUL byte reached in later chunks` (tiền tố hợp lệ nhưng hậu tố chứa byte UTF-8 không hợp lệ ném đúng `BAD_CONTENT`).
