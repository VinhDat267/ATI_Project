## Oracle bytes và fault

Hash SHA-256 của file `Tiến độ ATI\nAPI: Done\n` trong E01/E06/E07/E10/E13 là
`a353aebe142ac82ae7e447641cae07dfe90b7350c82fbeca33d6c5fc2f162691`. E01 có
notification `Đã lưu bản sao notes.txt.` và marker filesystem không được đếm như
`hub_receipt`.

E08 giữ đúng một durable filesystem marker dù packet chưa đến upstream và file
không tồn tại. E10 chứng minh trường hợp ngược lại: write thật đã tạo đúng bytes,
nhưng raw error/malformed acknowledgement hậu dispatch không được nâng thành
success. Trong cả E08 và hai mode E10, notification không được dispatch, attempt
write là `unknown`, receipt filesystem là `not_supported`, reconcile lần hai
không đổi kết quả và execute lại bị từ chối.

E14 giữ snapshot format v1/task_hub-only đọc được khi filesystem gateway không
có mặt. Run đã hoàn tất giữ ba attempt `confirmed` và hai receipt `confirmed`;
run pending với catalog in-memory stale bị chặn trước tool call, không đổi
snapshot hash, trace hoặc tổng `hub_receipts`.
