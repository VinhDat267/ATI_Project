# Nhật ký bàn giao

Mỗi phiên làm việc tạo **một file mới** trong thư mục này, trong cùng PR với thay đổi. Không sửa file của phiên khác. Vì mỗi phiên một file, hai PR làm song song không bao giờ xung đột ở đây.

Tên file: `YYYY-MM-DD-<agent>-<task>.md`, ví dụ `2026-10-08-codex-W2-01.md`. Đọc nhật ký gần nhất: sắp xếp theo tên file, xem 3 file cuối.

Mẫu:

```
# YYYY-MM-DD · <agent> · <task>

- **Đã làm:**
- **PR / commit:**
- **Kiểm tra đã chạy (lệnh và kết quả):**
- **Chưa làm / vấn đề phát hiện:**
- **Việc tiếp theo đề xuất:**
```
